# 12 недель

Трекер по системе «12 недель в году» (Брайан Моран): 3 цели, тактики, ежедневные отметки, недельный счёт с планкой 85%, разбор недели, воронка продаж, 13-я неделя на итоги.

- Одна HTML-страница, ставится на экран телефона (PWA).
- Данные хранятся в браузере. Синхронизация между устройствами — через личную ссылку `#k=...` (Supabase).
- Ссылка-шаблон `#tpl=...` переносит цели и тактики без отметок: так систему можно передать другому человеку.

Методы: Моран (12WY), McChesney/Covey (4DX), Gollwitzer (implementation intentions), Oettingen (WOOP), Clear («не пропускай дважды»), Matthews (отчёт партнёру).
